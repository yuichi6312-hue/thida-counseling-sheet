## 2. 決定事項（第2版に反映済み）

### 改訂のコンセプト
**「ひと振りの塩が、一本の芋を照らす」**（デザイナー）
ロゴから芋へ塩が落ちる縦の軸を1本通す。主役は**ロゴと芋の2つだけ**。

### 見出しの階層
1. ロゴ「日本橋 蜜塩芋」
2. 何の商品か：「宮古島の雪塩で食べる／冷やし焼き芋」（「冷やし焼き芋」を25mmの白・太字に拡大）
3. 決め台詞：「島を救った芋に、その島の塩を。」（**1本だけ**。筆文字をやめ、明朝の極太に）
4. 裏付け：「日本最古のさつまいも伝来地、宮古島」と「1597」の角印
5. 本文3行
6. 価格・原材料・QR・商標

### 個別の決定
| 項目 | 決定 | 経緯 |
|---|---|---|
| ロゴ | **元ポスターの手書き筆文字をベクター化して戻した** | ブランド・デザイナーの最優先要望 |
| 額縁 | 外枠を1.6mmの太い白枠に戻し、内枠は0.5mm | 元ポスターの「店の顔」。A4縮小時に細線が消えるのも防ぐ |
| 「甘いは太陽、しょっぱいは海。」 | **ポスターから外し、A4のPOP（価格の横）に移す** | 決め台詞が2本になり目が迷う（コピー・デザイナー・ブランド） |
| 写真 | 横幅いっぱい、高さ160mmに拡大 | デザイナー |
| 塩の粒 | 粒を大きく（直径1.2〜3mm）、ロゴ脇から芋の中心へ落とす | デザイナー |
| 1597 | 丸印→**金の角印**（46mm）。「宮古島に芋が渡った年」を5mmで添える | ブランド・デザイナー |
| 本文 | 旨屋の名前を入れ、脚色を削り、3行に（下記） | 宮古島・コピー |
| 正直な一文 | 「**芋は本土の畑から、塩は宮古島から。**」を原材料の上に追加 | 顧客・宮古島 |
| 価格 | 「手土産に　3本箱　1,980円（税込）」を金の帯で中央下に | 店頭・市場・顧客 |
| 英語・中国語 | 「Chilled Roasted Sweet Potato × Miyako Island Salt ／ 冰烤地瓜 × 宮古島雪鹽」を1行 | 顧客 |
| QR | 34mm角に拡大、宮古ブルーの枠。「物語のつづきは、こちら」「#蜜塩芋」 | SNS・宮古島。宮古ブルーはQRまわりだけに集約（ブランドの「面積5%以下」ルール） |
| 書体 | 筆文字はロゴだけ。それ以外は Zen Old Mincho（太さ500以上） | デザイナー（A4縮小でつぶれないように） |

### 本文（第2版）
> 1597年、漂流の末に芋かずらを宮古島へ持ち帰った長真氏旨屋（砂川親雲上）。
> その芋が、飢えから島の人々を救いました。
> 整体師の手で揉みほぐし、焼いて、冷やす。仕上げに雪塩をひとふり。

※「芋の神様の物語は、こちら」（コピー案）は、御嶽・神様を販促に使わないルール（宮古島連携）に合わせ、「物語のつづきは、こちら」を採用。

## 4. 次に作るもの（ポスターから外した情報の行き先）

**レジ横のA4 POP**（店頭販売・コピーの案）
- 「甘いは太陽、しょっぱいは海。」と価格表（1本／3本箱）
- 食べ比べの案内：「まず塩なしで、次に雪塩で」
- 日持ち・保存方法（冷蔵・当日中など）、のし・紙袋・まとめ買い
- 揉み焼きの説明
- 売上の一部を宮古島へ還元する取り組み

**吊り札**：「試食どうぞ」（店頭販売の要望。ポスターには入れず、出し入れできる札にする）

**SNS用の派生**（SNS）
- 4:5は「ロゴ＋芋＋塩」の構図に組み直す。物語の文章は画像に入れず、キャプションに回す。
- ストーリーズは上下14%を空け、QRの代わりにリンクスタンプを使う。
- 写真を差し替えるまでは投稿しない。

**ブランドの展開ルール**（ブランド戦略）
- 色は墨黒・生成りの白・芋の金・宮古の海の青の4色だけ。青は面積5%以下。
- 1597の角印は1種類に統一し、箱の封・かずらカード・Webのファビコンにも使う。
- 白の二重枠を「蜜塩芋の窓」として、箱の天面・カードの縁・Webの画像の枠にそろえる。
