## 1. 物語の素材（資料から分かったこと）

| 項目 | 内容 |
|---|---|
| 人物 | **長真氏旨屋（ちょうしんうじ・しおく）**。宮古島の要職「与人（ゆんちゅ）」を務めた役人。1632年に役人として最上級の**砂川親雲上（うるかぺーちん）**に昇進し、「砂川親雲上旨屋（うるかぺーちん・しおく）」と呼ばれる |
| 1594年（1回目の漂流） | 首里（琉球王府）からの帰り道に船が漂流し、中国の福建省に流れ着く。当時の中国では、ルソン（フィリピン）から伝わった芋の栽培が盛んになっていた |
| 3年間 | 中国に滞在し、芋の栽培を目にする |
| 1597年（2回目の漂流） | **芋かずら（芋の茎）を持って帰る途中、また漂流して九州にたどり着く**。それでも同じ年に宮古島へ帰り着く |
| その後 | 芋は「唐イモ」と呼ばれ、またたく間に島の主食になる。台風と干ばつで飢饉が繰り返された島の人々を、**飢えから救った** |
| 1642年（3回目の漂流） | 首里からの帰りにまた嵐に遭い、八重山に漂着する。その後病に倒れ、**宮古島に戻ることなく生涯を終える** |
| 芋ヌ主御嶽（ん・ぬ・しゅう・うたき） | 旨屋を「芋の神様」として祀る。宮古島市平良 西仲宗根の保里の東端。近くには船立御嶽、フサティ御嶽、漲水御嶽、仲宗根豊見親の墓などの史跡が集まる |
| 芋プゥイ | 1950年ごろまで、毎年8月ごろに行われた豊年感謝祭。島中から収穫した芋を持ち寄って供え、旗を掲げ、相撲を奉納する賑やかな祭りだった。芋の栽培が減ったことで途絶えた |
| 2012年「イモ計画」 | 2012年2月27日、宮古島市が**宮古島産甘藷プロジェクト推進協議会**を発足させる。行政・かんしょ研究会・観光・菓子店・経済界に加え、**東京の食品ギフト会社や飲食店の代表も委員**になった。「日本最古の伝来地として宮古島のイモ文化を再認識」し、6次産業化を目指す計画で、2021年度に面積95ha・収量2,100t・生産額2億7,300万円を目標にした |
| 印象的な言葉 | 講演した財団法人いも類振興会の理事長（当時）、狩谷昭男さんは次のように語った。「砂川親雲上旨屋は大恩人。先人に対する感謝の気持ちと宮古島産の甘藷が宝であるという利益を市民が共有することが大切」「（宮古島における）甘藷の歴史と文化に誇りを持って取り組んでほしい」（宮古毎日新聞 2012年2月28日） |

**注意（正直に扱う点）**
- 1597年は家譜にもとづく伝承で、1618年説や「本島（1605年）より後」とする説もある。「宮古島から琉球王国へ伝わった」という説も、真相は分かっていない。→ 表記は**「さつまいも発祥の地」**（オーナー判断で「諸説あり」は付けない）。聞かれたときに出典を示せるようにしておく。
- 宮古島の芋がそのまま本土へ広がったわけではない、とする指摘がある。→ **「東京の芋のご先祖は宮古島」とは言わない。**「日本のさつまいもの物語の、最初のページは宮古島」という語り方にする。
- 御嶽は信仰の場で、むやみに立ち入ってはいけない場所もある。写真の撮影や商業利用は、地元の方の考えを尊重して確認する。
- 2012年の計画の目標（2021年度）が達成できたかは未確認。2018年以降は基腐病で沖縄の芋の生産が大きく落ちている。宮古島市に現状を聞く。

## 2. 物語の核：4つの発見

### 発見①「三度、海に流された人」
旨屋は生涯で三度漂流した。一度目の漂流で芋に出会い、二度目の漂流の中でも芋かずらを手放さずに持ち帰り、島を飢えから救った。そして三度目の漂流の後、故郷に帰ることなく亡くなった。
**島に芋を届けた人は、自分は島に帰れなかった。**
蜜塩芋の物語の主人公は、芋ではなく**「海を越えて、大切なものを届けた人」**。

### 発見②「旨屋」は「しおく」と読む
**旨（うまい）＋しお（塩）**。偶然ですが、「旨い・塩・芋の神様」が一つの名前に重なっています。ネーミングで最大の武器になります（→4章）。

### 発見③「ふたつの起点」
- **宮古島**：日本のさつまいもの起点の島
- **日本橋**：日本の道の起点（日本国道路元標がある、五街道の出発点）

**芋の起点と、道の起点。** 1597年に海を越えた一本の芋かずらの物語が、400年あまりを経て、日本中の道が始まる日本橋に届く。この店が、ふたつの起点をつなぐ「橋」になる。

### 発見④「島は、すでに東京と組もうとしていた」
2012年の「イモ計画」の協議会には、東京の食品ギフト会社や飲食店も加わっていた。島はかつて、芋の物語を宝として、島の外とつながろうとしていた。
**蜜塩芋は、島が始めたその計画を、東京の側から受け止めて引き継ぐプロジェクトになれる。** 宮古島市に話をするときの最も強い入り口になる。

## 3. ブランドストーリー（本文）

### ロング版（Web・パンフレット用）

> **一本のかずらが、海を越えた。**
>
> 1594年、宮古島の役人・旨屋（しおく）は、首里からの帰り道で嵐に遭い、遠く中国・福建の浜へ流れ着きました。
> そこで彼が見たのは、南の国から伝わったばかりの、やせた土地でも力強く育つ芋でした。
>
> 異国で過ごした三年。島へ帰る旨屋の手には、一本の芋かずらがありました。
> 帰りの船もまた嵐に遭い、たどり着いたのは九州。それでも彼はかずらを手放さず、1597年、ようやく故郷の土を踏みます。
>
> 台風と干ばつのたびに飢えに苦しんできた島で、旨屋が分けたかずらは、またたく間に畑を覆い、島の人々の命をつなぐ主食になりました。
>
> 旨屋はその後も海を渡り続け、三度目の嵐のあと、故郷に帰ることなく生涯を終えます。
> 島の人々は彼を「芋ヌ主（んぬしゅう）＝芋の神様」として祀り、かつては毎年夏に、島中の芋を持ち寄る感謝の祭り「芋プゥイ」を開いてきました。
> 宮古島は、日本で最初にさつまいもが伝わった、さつまいも発祥の地です。
>
> それから四百年あまり。
> 日本中の道が始まる場所、東京・日本橋で、私たちは焼き芋を焼いています。
> 仕上げにひとつまみ振るのは、宮古島の地下にたくわえられた海の水から生まれた雪塩。
> 整体師の手で芋の繊維をやさしく揉みほぐし、じっくり焼いて、冷やす。
>
> 芋の起点・宮古島と、道の起点・日本橋。
> 海を越えて島に芋を届けた旨屋のように、今度は私たちが、東京と宮古島のあいだに橋をかけます。
>
> **蜜塩芋。ひと口で、島へ。**

### ショート版（POP・SNS用・約100字）

> 1597年、嵐に流されながらも一本の芋かずらを手放さず、宮古島へ持ち帰った男がいました。島を飢えから救った彼を、島の人々は「芋の神様」と呼びます。その島の雪塩で仕上げる、日本橋の焼き芋。

## 4. ネーミング（マーケティング視点での検討）

### 4-1. 誰に売るか（東京のターゲット）

| セグメント | 特徴 | 刺さる言葉 |
|---|---|---|
| ① 日本橋のオフィスワーカー（30〜50代） | 平日昼・手土産需要。「理由のある手土産」を求める | 物語・由来・限定 |
| ② 国内観光客・百貨店の来店客 | 日本橋のブランド・老舗感を好む | 日本橋・起点・江戸 |
| ③ インバウンド | 「日本の焼き芋文化」への関心が高い（台湾・香港・タイ） | 1597・God of Potatoes・Japan's first |
| ④ 宮古島ファン／沖縄出身者（首都圏） | 「宮古島ロス」・故郷を応援したい | 旨屋・ンーヌ主・雪塩・島の言葉 |

**④は最初に熱心なファンになり、口コミを広げてくれる層**です。地元の言葉と人物の名前をきちんと扱うことが、この層の信頼につながります。

### 4-2. 評価軸
1. **一瞬で伝わるか**（何の商品か分かる）
2. **物語を背負えるか**（なぜ宮古島かを語れる）
3. **覚えやすく、検索しやすいか**（SNS・口コミ）
4. **ほかと区別できるか／商標を取れるか**
5. **地元が誇りに思えるか**（架け橋になるための条件）

### 4-4. 推奨：三層のネーミング

```
ブランド（傘）：  蜜塩芋（みつしおいも）
看板商品：       蜜塩芋「旨屋 ‐しおく‐」
英語／記号：     1597 MITSU-SHIO-IMO
コンセプト：     芋の起点から、道の起点へ。
```

- **「蜜塩芋」は変えない**：すでにお客様がついている名前で、何の商品かがすぐ分かる。宮古島らしさは名前ではなく「物語」と「看板商品名」で足す。
- **看板商品を「旨屋（しおく）」にする**：
  - 店頭での会話が生まれる：「しおく、って何ですか？」→「宮古島の芋の神様の名前なんです。旨いに屋と書いて、しおく」。**この一往復が、宮古島の話をする入り口になる。**
  - 検索で他とかぶらない。SNSで「#しおく」と名前を付けて呼んでもらえる。
- **「1597」を英語・パッケージの記号に**：インバウンド向けと、デザイン上のアイコン（焼き印・シール）にする。
- **店名・ブランド表記**：「日本橋 蜜塩芋」はそのまま残す。宮古島の要素は、看板商品・物語・雪塩で伝える。

### 4-5. 名前の使い方の注意
- 「旨屋」は実在の人物で、信仰の対象でもある。使う前に、**宮古島市の文化財担当・地元の郷土史研究会・御嶽を守る地域の方**に趣旨を説明し、了解を得る。了解が得られなければ、看板商品名は「かずら」にする。
- 商標：「蜜塩芋」「しおく／旨屋」「1597」について、J-PlatPatで先に登録されていないか調べ、出願を検討する（菓子・野菜加工品の区分）。
- 「芋の神様の焼き芋」のように、ご利益をうたう表現はしない。

### 4-6. 名前の検証方法（2週間でできるテスト）
1. **店頭POPで比べる**：1週目は「蜜塩芋」、2週目は「蜜塩芋『旨屋』」と、POPだけを変えて販売数と「これ何？」と聞かれた回数を記録する。
2. **Instagramストーリーの投票**：候補B／C／Dで投票してもらう。
3. **宮古島出身者に聞く**：首都圏の宮古出身者の会や、宮古島の事業者（雪塩など）に5〜10人ほどヒアリングし、⑤「地元が誇りに思えるか」を確かめる。
4. 判断の基準：③ヒアリングで違和感が出なければ、販売数と会話数の多い案を採用する。

## 5. 「架け橋」を形にする施策

| 施策 | 中身 | 東京→宮古島 | 宮古島→東京 |
|---|---|---|---|
| **かずらカード** | 商品に、旨屋の物語と宮古島の地図・観光とふるさと納税のQRを載せた小さなカードを付ける | 送客 | — |
| **日本橋 芋プゥイ（芋の感謝祭）** | 1950年ごろに途絶えた宮古島の豊年感謝祭「芋プゥイ」にちなみ、毎年8月ごろに日本橋で芋に感謝する日を開く。宮古島の物産・泡盛・三線と組み合わせる。将来は宮古島での復活を島の方々と一緒に目指す。※地元の行事名なので、了解を得てから名前を使う | 発信 | 物産販売・祭りの復活 |
| **イモ計画の東京パートナー** | 2012年に宮古島市が始めた甘藷プロジェクトの現状を聞き、「東京側の販路・発信の窓口」として協力を申し出る | 販路 | 島の芋文化の発信 |
| **1本＝1円〜の島への恩返し** | 売上の一部を、宮古島市（企業版ふるさと納税）や、文化財・御嶽の保全に役立ててもらう | 還元 | — |
| **旨屋の道をたどる旅** | 宮古島へ行く人向けに、芋ヌ主御嶽（参拝マナー付き）・雪塩ミュージアム・漲水御嶽をめぐるモデルコースを紹介する | 送客 | — |
| **島からの逆輸入** | 宮古島の泡盛・黒糖・マンゴーを使った季節限定の蜜塩芋（例：黒糖蜜塩芋）を作る | — | 物産の販路 |
| **島で食べる蜜塩芋** | 将来、宮古島のイベントや店で「日本橋から里帰りした焼き芋」として売る（本土で加熱した冷凍品なので島に持ち込める） | — | 東京の名物を島へ |

**合言葉：「旨屋が海を越えて芋を運んだように、私たちは東京から島へ人を運ぶ」**

## 6. 次の一歩
1. 宮古島の郷土史研究会または市の文化財担当に連絡し、物語の内容と「旨屋」の名前を使うことについて相談する。
2. **2026年11月19日の宮古島共創フォーラム（有楽町）**で、この物語と「ふたつの起点」のコンセプトを、宮古島市と島の事業者に紹介する。「2012年のイモ計画を東京から引き継ぎたい」と伝える。
3. 店頭で、2週間のネーミングテスト（4-6）を行う。
4. ポスターとWebの文言を、この物語（ショート版）に合わせて更新する。
