# Codex 実装タスク：「宮古島 蜜塩芋」店頭ポスター

> このファイルを丸ごと Codex に渡してください。

> 背景は同じフォルダの `企画書.md` にあります。

## 目的
日本橋の店頭に貼る「宮古島 蜜塩芋」のポスターを作る。今の「日本橋 蜜塩芋」ポスター（`docs/mitsushioimo-miyakojima/reference-current-poster.jpg`）の雰囲気をそのまま引き継ぎ、宮古島の要素（日本最古のさつまいも伝来地・雪塩）を前面に出した宮古島バージョンにする。

## 成果物
```
public/mitsushioimo/poster/
  index.html     # 印刷用ポスター（A2縦 420×594mm。同じレイアウトで A3・A4 にも縮小印刷できること）
  poster.css
  photo.jpg      # 焼き芋の写真の差し替え枠（下記参照）
  README.md      # 写真の差し替え方法、印刷・PDF化の手順、文言の変え方
```
- `index.html` をブラウザで開き、印刷（PDFとして保存）すれば入稿用の PDF になること。`@page { size: 420mm 594mm; margin: 0 }` を指定し、背景色・背景画像が印刷されるよう `-webkit-print-color-adjust: exact; print-color-adjust: exact` を付ける。
- 画面で見るときは、ウィンドウ幅に合わせて縦横比 1:√2 のまま縮小表示する。
- 任意：Playwright がある環境なら `poster.pdf` と `poster.png`（幅2480px）も書き出す。ない場合は README に手順だけを書く。

## 絶対に守ること
1. 作業してよいのは `public/mitsushioimo/poster/**` だけ。既存ファイルは一切変更しない（`src/`、ルートの設定ファイル、`public/sw.js`、`public/ryoshusho/`、`.github/` など）。
2. 外部 JS は使わない。フォントは Google Fonts のみ可。
3. 文言は下の「確定文言」をそのまま使う。勝手に言い回しを足したり、断定に変えたりしない。
   - 「原種」「宮古島原産」「宮古島産の芋」とは書かない（芋の産地は本土。今は茨城県）。
   - 揉み焼きについて、健康効果をうたう表現は入れない。
4. 写真について：参考ポスターの写真は文字と一体になっていて流用できないので、`photo.jpg` は仮画像にする。焼き芋のシルエットを CSS や SVG で描いた暗いプレースホルダーでよい。後で本物の写真に差し替えると、トリミング（`object-fit: cover`）だけでそのまま収まること。

## デザイン（参考ポスターを踏襲）
- 背景は黒（`#0B0B0B`）で、内側に細い白の二重枠（参考ポスターと同じ）。
- 右上に縦書きで小さく「日本橋」、その下に大きく筆文字の「蜜塩芋」（縦書き・白）。その上か横に「宮古島」を金色で添える。
  - フォント：Google Fonts「Yuji Syuku」または「Yuji Boku」（筆文字風）。本文は「Zen Old Mincho」。
- 左上に縦書きで原材料表示（白・明朝）。
- 中央：焼き芋の写真（photo.jpg）。上から塩が降るような白い粒のきらめき（CSS か SVG の点で描く。参考ポスターと同じ演出）。
- 下部：横書き・中央揃えの本文。見出し行は太字の白。
- アクセント：宮古ブルー `#1F8FB0` を1か所だけ（例：「宮古島」の下の細い波線、または枠の内側の一辺）。金 `#C9A24A` は「宮古島」の文字と年号に使う。
- 文字は印刷時に十分読める大きさにする。A2 で本文が 9mm（約26pt）以上。

## 確定文言

### 縦書き（右上）
- 小：日本橋
- 大（筆文字）：蜜塩芋
- 金：宮古島

### 縦書き（左上・原材料）
- さつまいも　茨城県産ブランド芋
- 塩　沖縄県宮古島産　雪塩

※芋の産地は今後変わる可能性がある。CSS 変数や HTML の1か所にまとめ、README に変え方を書く。

### 下部の本文（横書き・中央揃え）
**日本最古のさつまいも伝来地、宮古島**
**1597年、宮古島に甘藷が伝わったと伝わる。そして焼き芋は、江戸の町で愛された。**

選び抜いた国産の芋に
琉球石灰岩で濾過された地下海水から生まれる雪塩を。
さらに整体師の揉みの技で芋の繊維をやわらげ
深い甘さを引き出す"揉み焼き技法"。
こだわり抜いた冷やし焼き芋です。

### 最下部（小さく）
- 「雪塩」は株式会社宮古島の雪塩の商標です。
