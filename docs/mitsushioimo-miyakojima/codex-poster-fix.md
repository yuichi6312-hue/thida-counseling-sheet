## 直してほしい点
1. **下半分（全体の約45%）が真っ黒な空白になっている。**
   要素をすべて mm 単位で指定し、A2（420×594mm）の高さいっぱいに配分する。目安は次のとおり（上から）。
   - 0〜48%：タイトルと塩の粒
   - 40〜75%：焼き芋の写真（タイトル部分と少し重ねる）
   - 75〜95%：本文
   - 95〜100%：最下部の表記
   CSS グリッドの `grid-template-rows` で比率を固定する。
2. **「蜜塩芋」が小さく、普通の明朝になっている。**
   - 参考ポスターと同じく、縦書きで**ポスターの高さの約45%**を占める大きさにする（1文字あたり約70mm）。
   - フォントは Google Fonts「Yuji Syuku」を `<link>` で確実に読み込む。印刷前に `document.fonts.ready` を待つ。
   - 読み込めなかったときの代替は「Yuji Boku」→「Zen Old Mincho」。
3. **写真が小さい。**
   - 枠の内側の横幅いっぱいに広げ、高さは約35%にする。
   - 上下の端は黒へのグラデーションで背景になじませる（今の処理は良いので維持）。
4. **本文が小さい。**
   - 見出し「日本最古のさつまいも伝来地、宮古島」は約16mm。
   - 2行目（1597年〜）は約11mm。
   - 説明文は約9mm、行間1.9。
5. **「宮古島」（金）が小さく、下線が中途半端。**
   - 「日本橋」と同じ列の上に置くか、「蜜塩芋」の左隣に縦書きで約30mmの大きさで置く。
   - 下線はやめ、宮古ブルーの細い縦線を1本、文字の横に添える。
6. **原材料の縦書き**は約8mmに拡大し、左上の余白を詰める。
