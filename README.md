# カウンセリングシート | THIDA

トレーニングジム・整体向けのカウンセリングシート（問診票・カルテ）アプリです。

- お客様がiPadを渡されて直接記入する運用を想定した入力画面と、来店情報・身体情報・同意事項・スタッフ記入欄を扱うスタッフ画面を分離
- 印刷用カルテビューはA4 1枚に収まるレイアウト
- ホーム画面に追加してアプリのように使えるPWA対応（オフラインでも起動可能）

## 開発

```sh
npm install
npm run dev
```

## ビルド

```sh
npm run build
```

`main` ブランチへのpush、または手動実行（workflow_dispatch）で GitHub Pages に自動デプロイされます。
