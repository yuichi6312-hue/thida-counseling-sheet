# 日本橋 蜜塩芋 ポスター（A2 縦 420×594mm）

## ファイル
- `index.html` … ポスター本体（ブラウザで開くと画面に合わせて縮小表示）
- `poster.css` … デザイン
- `photo.jpg` … 焼き芋の写真（**差し替え推奨**）
- `salt.svg` … 降りそそぐ塩の粒
- `poster.pdf` … 入稿用 PDF（A2 1枚）
- `poster.png` … 確認用の画像

## 印刷・PDF化
Chrome で `index.html` を開き、印刷 →「PDFに保存」。用紙サイズは自動で A2 になります。「背景のグラフィック」にチェックを入れてください。A3・A4 にはプリンタ側で縮小印刷できます。

## 写真の差し替え
今の `photo.jpg` は既存ポスターから切り出したもので解像度が低く、A2 で印刷すると粗くなります。
文字の入っていない元写真（横長、幅 4000px 以上が目安）を同じ名前 `photo.jpg` で上書きしてください。トリミングは自動です。

## 文言の変え方
`index.html` を直接編集します。
- 芋の産地：`data-field="imo"` の行（例：茨城県産ブランド芋）
- QR コード：`.qr-box` の枠に QR 画像を入れる（例：`<img src="./qr.png" style="width:100%">`）

## 表現ルール
- 宮古島は「日本最古のさつまいも伝来地」と書く（「発祥の地」「原種」「宮古島産の芋」は使わない）
- 揉み焼きは調理工程の説明のみ。健康効果はうたわない
- 「雪塩」は株式会社宮古島の雪塩の商標。使用表記はメーカーに確認する
